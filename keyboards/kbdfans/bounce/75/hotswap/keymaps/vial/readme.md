Vial Support for KBDfans Bounce 75 Hotswap.

Run the following command to build the firmware.
```sh
qmk compile -kb kbdfans/bounce/75/hotswap -km vial
```

[QMK Settings](https://get.vial.today/changelog/release-0.4.html#qmk-settings), [Repeat Key](https://get.vial.today/manual/alt-repeat-key.html), and [Key Overrides](https://docs.qmk.fm/features/key_overrides) are disabled to save space.

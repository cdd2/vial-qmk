Vial Support for KBDfans Bounce Pad.

Run the following command to build the firmware.
```sh
qmk compile -kb kbdfans/bounce/pad -km vial
```

[Repeat Key](https://get.vial.today/manual/alt-repeat-key.html), and [Key Overrides](https://docs.qmk.fm/features/key_overrides) are disabled to save space.

[QMK Settings](https://get.vial.today/changelog/release-0.4.html#qmk-settings) can be disabled instead of the features above to compile within space limitations.
